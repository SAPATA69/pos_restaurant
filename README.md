
## การแก้รายการที่สั่งผิด

- รายการที่ยังเป็น **Draft** สามารถกด `ลบ` ออกจากบิลได้ก่อนส่งเข้าครัว
- รายการที่ส่งเข้าครัวแล้วให้ใช้ `ยกเลิกคิว` ซึ่งเป็นการยกเลิกแบบ Soft Cancel เพื่อรักษาประวัติ
- รายการที่ยกเลิกจะไม่ถูกคิดเงินและจะไม่ปรากฏในคิวครัว
- รายการที่ชำระเงินแล้วไม่อนุญาตให้ยกเลิกโดยตรง เพื่อป้องกันยอดเงินคลาดเคลื่อน ต้องดำเนินการคืนเงินก่อนในระบบจริง
