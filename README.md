# POS ร้านอาหาร + ระบบคิวครัว

เว็บแอปพลิเคชันต้นแบบด้วย Flask และ PostgreSQL รองรับนั่งรับประทานที่ร้าน/ซื้อกลับบ้าน, คิวครัว, ตัวเลือกอาหาร, QR ทดลอง, ใบเสร็จ และรายงานการขาย

## ฟังก์ชันหลัก

- รับออเดอร์แบบนั่งร้านและซื้อกลับบ้าน
- Workflow อาหาร: Draft → ส่งเข้าครัว → กำลังทำ → พร้อมเสิร์ฟ → เสิร์ฟแล้ว
- QR Payment สำหรับสาธิต พร้อมใบเสร็จรูปแบบร้านอาหาร
- ใบเสร็จมีโหมดพิมพ์เฉพาะเอกสาร โดยซ่อนเมนูและปุ่มทั้งหมดอัตโนมัติ
- Dashboard ยอดขายตามวัน/ช่วงวันที่ พร้อมยอดรวมและจำนวนบิล
- ประวัติการชำระเงินสำหรับตรวจสอบรายการและเปิดใบเสร็จ/สลิป
- รายงานเมนูขายดี โดยรวมราคาตัวเลือกเพิ่มเติมในยอดขาย
- UI ธีมสีเขียว รองรับคอมพิวเตอร์และแท็บเล็ต

## Workflow หลัก

1. พนักงานเพิ่มอาหารลงบิลในสถานะ **ยังไม่ส่งครัว (Draft)**
2. กด **ส่งรายการใหม่เข้าคิวครัว**
3. ครัวกด **เริ่มทำ → พร้อมเสิร์ฟ → เสิร์ฟแล้ว**
4. แคชเชียร์รับชำระเงินและพิมพ์ใบเสร็จ
5. ตรวจสอบย้อนหลังที่เมนู **ยอดขาย** → **ประวัติการชำระเงิน**

## เมนูรายงาน

- `/reports/` — ยอดขายวันนี้หรือช่วงวันที่ที่เลือก
- `/reports/payments` — ประวัติการชำระเงินและลิงก์ดูใบเสร็จ/สลิป
- `/reports/best-sellers` — เมนูขายดี

## QR Payment

โหมด `QR ทดลอง` สร้าง QR Code ในหน้า checkout ด้วย QR payload สำหรับการสาธิตเท่านั้น ไม่ได้เชื่อมต่อธนาคารจริง หากต้องการใช้จริงให้ตั้งค่า `PROMPTPAY_ID` เป็นหมายเลขบัญชี/พร้อมเพย์ของร้าน และพัฒนาตัวสร้าง Thai QR Payment ตามมาตรฐานธนาคารก่อนใช้งานจริง

## ตั้งค่าและรัน

```bash
python -m venv venv
# Windows: venv\\Scripts\\activate
# Linux/macOS: source venv/bin/activate
pip install -r requirements.txt
python seed_db.py
python run.py
```

เปิด `http://localhost:5000` หรือ `http://localhost:5000/auth/login`
